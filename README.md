> **The next-generation visual file manager featuring instant previews and the proprietary `.zex` container format.**

## Key Features

- **Instant Preview**: Native, high-performance real-time previews for videos, images, and 3D models.
- **Proprietary `.zex` Container Format**:
  - **No More Fragmented Files**: Merge and compress game directories containing tens of thousands of files into a single `.zex` file, drastically improving management efficiency.
  - **Media Archive Aggregation**: Pack video and image collections into a single `.zex` file **with zero-decompression instant opening and previewing**.
- **Human-Centric Interaction**: Ditch cumbersome traditional file operations for a more elegant, intuitive interface and browsing logic.

> **集成即时预览与独创 `.zex` 格式的下一代可视化文件管理器。**

## 核心特性

- **直接预览**：原生支持视频、图片与 3D 模型等资源的高性能实时预览。
- **独创 `.zex` 容器格式**：
  - **告别海量碎片文件**：将包含数万个文件的游戏目录合并压缩为单一 `.zex` 文件，极大优化管理效率。
  - **媒体单文件聚合**：视频、图片库可压缩为单个 `.zex` 文件，**支持免解压即时打开与预览**。
- **人性化交互**：弃用繁杂的传统文件操作，提供更优雅、直觉化的操作界面与浏览逻辑。
